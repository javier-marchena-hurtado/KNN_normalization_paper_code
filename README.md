# KNN normalization paper code

Code to reproduce the figures of the paper on KNN normalization of protein (CITE-seq/ADT) data. The normalization itself is implemented in the separate `knn_normalization` Python package, which this repository imports (`import knn_normalization as knn`).

## Repository contents

### Code

| File | Description |
|---|---|
| `code_figures.ipynb` | Main notebook. Generates the figures of the paper, organized in sections: Figure 1C, Figure 2, Figure 3, Figure 4, and Supplementary Figures 1B, 2, 3 and 4. |
| `utils.py` | Helper functions used by the notebook: PCA/neighbors/UMAP/Leiden wrappers, total-count calculations, CLR and library-size normalization, application of all normalization methods per sample (`apply_normalization_methods`, `normalize_per_sample`), bounded-maximum ARI computation, boxplots comparing methods, size-factor comparisons, and removal of cells with very high total counts. |
| `scmultisim_code.R` | R script that simulates paired RNA and protein data with [scMultiSim](https://github.com/ZhangLabGT/scMultiSim) (5000 genes, 50 proteins, 1000 cells, 3 cell types) and exports it to `.h5ad` through Seurat. |
| `code_figures_env.yml` | Conda environment with the exact package versions used to run the notebook. |

### Data

The `.h5ad` files are excluded from git (see `.gitignore`) because of their size.

| File | Description |
|---|---|
| `scmultisim_rna_data.h5ad`, `scmultisim_protein_data.h5ad` | Simulated RNA and protein counts produced by `scmultisim_code.R` (used in Figure 2). |
| `Immune_colon_rna_data.h5ad`, `Immune_colon_protein_data.h5ad` | Colorectal cancer immune-cell CITE-seq dataset, RNA and protein (used in Figure 3, Supplementary Figures 3 and 4). |
| `Haoetal_rna.h5ad`, `Haoetal_protein.h5ad` | Hao et al. PBMC multimodal CITE-seq dataset converted to `.h5ad` (used in Supplementary Figure 2; conversion code is in the notebook). |
| `fig_1C_total_protein_counts_per_celltype_per_sample.csv` | Mean protein counts per cell type and sample across public datasets (Figure 1C). |
| `supp_fig_4A_ARI_n_neighbors.csv`, `supp_fig_4B_SNR_n_neighbors.csv` | ARI and signal-to-noise ratio (SNR) as a function of the number of neighbors (Supplementary Figures 4A-B). |
| `supp_fig_4C_ARI_pseudocounts.csv`, `supp_fig_4D_SNR_pseudocounts.csv` | ARI and SNR as a function of the pseudocount value (Supplementary Figures 4C-D). |

### Outputs

`figures/` contains the generated figure panels (mostly `.svg`, some `.png`) plus intermediate result tables (ARI scores per method, n-neighbors analysis, `scib_results.csv`). File names start with the figure they belong to (e.g. `Figure_3A_...`, `Supplementary_Fig_2C_...`). This folder is also excluded from git.

## Methods compared

Uncorrected (raw/log1p) protein data, library-size normalization, CLR normalization (across proteins, across antibodies, and the Stoeckius variant), KNN normalization (neighbors defined from protein or RNA, per sample or across samples), and, for integration benchmarks, arcsinh/CLR/KNN-normalized data combined with CytoVI or Harmony, evaluated with ARI, SNR and `scib-metrics`.

## Usage

```bash
conda env create -f code_figures_env.yml
conda activate python_3.14
jupyter lab code_figures.ipynb
```

Run the notebook from this directory. Some cells read data from absolute paths on the original cluster (e.g. the RNA object `rna_v15.h5ad` used in Supplementary Figure 3), so adjust these paths to your setup. The simulated data can be regenerated by running `scmultisim_code.R` in R with Seurat, SeuratData, SeuratDisk, scMultiSim and ape installed.
